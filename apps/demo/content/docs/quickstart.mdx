Two paths: the **full setup** (Next.js + Prisma — the production shape) or the **zero-server** one (60 seconds, everything in the browser).

## Full setup — Next.js + Prisma

### 1. Install

```bash
npm i @instafix/widget @instafix/adapter-prisma
```

You'll need Prisma already set up, plus a client singleton at `@/lib/prisma`. If you don't have one:

```ts
// src/lib/prisma.ts
import { PrismaClient } from "@prisma/client";

const globalForPrisma = globalThis as unknown as { prisma?: PrismaClient };
export const prisma = globalForPrisma.prisma ?? new PrismaClient();
if (process.env.NODE_ENV !== "production") globalForPrisma.prisma = prisma;
```

### 2. Scaffold

```bash
npx @instafix/cli init
```

Confirm both prompts: the CLI adds the two InstaFix models to your Prisma schema and generates the API route (`app/api/instafix/route.ts`, or under `src/app/` if that's your layout). Then push the schema to your database:

```bash
npx prisma db push
```

### 3. Mount the widget

```tsx
// Anywhere client-side — e.g. your root layout
"use client";
import { useInstaFix } from "@instafix/widget/react";

export function Feedback() {
  useInstaFix({ endpoint: "/api/instafix", projectName: "my-project" });
  return null;
}
```

Run your dev server and look bottom-right: the InstaFix button is there. Draw a rectangle on anything, type a comment, hit Send.

By default the widget shows in development but **never in production builds** — that's the point: clients review on dev/staging URLs. For a staging environment that builds in production mode, pass `forceShow: true`.

### 4. Triage what comes in

```tsx
import { InstaFixInbox } from "@instafix/dashboard";

<InstaFixInbox projects="my-project" endpoint="/api/instafix" theme="auto" />
```

That's the whole loop. From here: [widget options](/docs/widget/configuration) · [screenshots](/docs/widget/screenshots) · [auth & security](/docs/adapters/prisma#the-security-model-honestly).

## Zero-server setup

No backend, no database — feedback lives in the visitor's browser. Perfect for prototypes and demos:

```bash
npm i @instafix/widget @instafix/adapter-localstorage
```

```ts
import { initInstaFix } from "@instafix/widget";
import { LocalStorageStore } from "@instafix/adapter-localstorage";

initInstaFix({
  store: new LocalStorageStore(),
  projectName: "my-demo",
  forceShow: true,
});
```

This documentation site runs exactly this setup — try the widget right here.
